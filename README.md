## Sobre mí

Desarrollador de software enfocado en **Backend** y arquitectura de sistemas. Especializado en la creación de soluciones escalables, diseño de APIs REST y aplicaciones web en producción, aplicando patrones de diseño, seguridad y persistencia relacional.

- **ClubReserva (SaaS):** Creador y mantenedor de una plataforma multi-tienda de catálogos y gestión de pedidos para WhatsApp en producción con negocios activos.
- **Especialización Backend:** Diseño e implementación de servicios REST con **Java y Spring Boot** (Spring Security, autenticación JWT, Spring Data JPA / Hibernate, MySQL).
- **Desarrollo Fullstack:** Aplicaciones web con **PHP / Laravel**, y desarrollo de interfaces con **React, TypeScript y TailwindCSS**.
- **Desarrollo asistido por IA:** Flujo de trabajo acelerado con herramientas avanzadas (**Antigravity, Claude, Gemini, DeepSeek**) para testing, refactorización y documentación técnica.
- **Objetivo profesional:** Incorporarme a un equipo de ingeniería backend para construir sistemas de alto rendimiento y código mantenible.
