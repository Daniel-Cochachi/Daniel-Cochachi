## Lo que busco

Mi primera oportunidad como desarrollador backend: prácticas o puesto junior, en un equipo donde pueda trabajar con código real y seguir creciendo en Java y Spring Boot.

## En qué trabajo

- **APIs REST con Spring Boot:** arquitectura por capas (controller, service, repository), DTOs, manejo de errores, JPA/Hibernate y MySQL.
- **Seguridad:** autenticación con JWT y permisos por rol (`ADMIN` / `USER`) con Spring Security.
- **PHP con patrón MVC** sin framework, y sitios web con Astro desplegados en Vercel y Netlify.
